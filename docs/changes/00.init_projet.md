# Plan d'initialisation du projet Rugby Stats Collector

## Vue d'ensemble

Application de collecte d'événements de match de rugby avec synchronisation offline-first vers Firestore.

**Stack technologique:**
- **Frontend:** Angular 18+ avec PWA/Service Worker
- **Cache local:** IndexedDB via Dexie.js
- **File d'opérations:** Queue locale (pending/synced/conflict)
- **Backend:** Firestore (Cloud Firestore)

---

## Architecture générale

```
┌─────────────────────────────────────────┐
│   Angular PWA - App Interface           │
│   (installable, offline-capable)        │

               │
```

**Structure du schéma:**
```typescript
import { Evenement, Match, Manager, Equipe } from '../models/datamodel';
import { SyncOperation } from '../models/datamodel';

export interface SyncMetadata {
  id: number;
  matchId: number;
  lastSync: string;       // ISO 8601
  lastFullSync: string;   // ISO 8601
  pendingCount: number;
}

export class RugbyStatsDatabase extends Dexie {
  evenements!: Table<Evenement>;
  operations!: Table<SyncOperation>;
  matches!: Table<Match>;
  managers!: Table<Manager>;
  equipes!: Table<Equipe>;
  syncMetadata!: Table<SyncMetadata>;

  constructor() {
    super('RugbyStatsDB');
    this.version(1).stores({
      evenements: '++id, matchId, instant, createdAt',
      operations: '++id, evenementId, matchId, status, createdAt',
      matches: '++id, equipeId, date',
      managers: '++id',
      equipes: '++id, saison',
      syncMetadata: '++id, matchId'
    });
  }
}
```

## Phase 5 : File d'opérations locale

### 5.1 Queue Service (`src/app/services/queue.service.ts`)

**Fonctionnalités:**

1. **Gestion d'état des opérations**
   - Ajouter une opération: `pending`
   - En cours de sync: `syncing`
   - Succès: `synced`
   - Conflit: `conflict`
   - Échec: `failed`

2. **Persistance**
   - Sauvegarder queue en IndexedDB (table `operations`)
   - Reprendre après redémarrage
   - Filtrer par matchId et status

3. **Retry logic**
   - Exponential backoff: 1s, 2s, 4s, 8s, 16s
   - Max retries: 5
   - Marquer comme `failed` après max retries

4. **Conflict resolution**
   - Last-write-wins (comparer timestamps `syncedAt`)
   - Marquer comme `conflict` pour examen manuel
   - Notification à l'utilisateur via Observable
   - Option de merge/discard manuel

5. **Monitoring**
   - Observable du nombre d'opérations `pending` par matchId
   - Observable des `conflict` pour UI
   - Événement de sync réussi/échoué

**Actions:**
- [ ] Implémenter `QueueService`
- [ ] Ajouter retry strategy avec exponential backoff
- [ ] Implémenter conflict handler
- [ ] Tester avec mode offline

**Firestore Rules (sécurité):**
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Managers accèdent à leurs propres données
    match /managers/{managerId} {
      allow read, write: if request.auth.uid == managerId;
    }
    
    // Teams: lecture si manager, écriture si propriétaire
    match /teams/{teamId} {
      allow read: if request.auth.uid in resource.data.managerIds;
      allow write: if request.auth.uid in resource.data.managerIds;
      
      // Matches et événements: accès via équipe
      match /matches/{matchId} {
        allow read, write: if request.auth.uid in get(/databases/$(database)/documents/teams/$(teamId)).data.managerIds;
        
        match /evenements/{evenementId} {
          allow read, write: if request.auth.uid in get(/databases/$(database)/documents/teams/$(teamId)).data.managerIds;
        }
      }
    }
  }
}
```

**Pattern réactif (FormGroup):**
```typescript
import { FormBuilder, ReactiveFormsModule } from '@angular/forms';

export class MyComponent {
  form = this.fb.group({
    email: ['', [Validators.required, Validators.email]],
    nature: ['SCORE'],
    type: [''],
    equipe: ['NOUS'],
    resultat: [''],
    minute: [''],
    commentaire: ['']
  });
  
  constructor(private fb: FormBuilder) {}
  
  // Cascade: quand nature change, maj les sous-types
  ngOnInit() {
    this.form.get('nature')?.valueChanges
      .pipe(
        tap(nature => this.updateSubtypes(nature))
      )
      .subscribe();
  }
}
```
