# Phase 02b - Authentification Locale (Optionnel)

## Contexte

Cette extension de Phase 02 permet à l'application de fonctionner **complètement offline** sans Firebase pendant le développement/testing. Les utilisateurs sont authentifiés via une base IndexedDB locale.

## Prérequis

- Phase 01 (Angular setup) ✅
- Phase 02 (Firebase Auth) ✅
- Dexie.js déjà installé

## Architecture

### Modes d'Authentification

| Mode | Stockage | Sync | Cas d'Usage | Online Required |
|------|----------|------|------------|-----------------|
| **Local** | IndexedDB | ❌ Non | Dev, Test, Offline | Non |
| **Firebase** | Firebase Auth | ✅ Oui | Production | Oui |

### 2. Créer LocalAuthService

Créer `src/app/core/services/local-auth.service.ts`:

```typescript
import { Injectable } from '@angular/core';
import { db } from '../database/rugby-stats.database';
import { LocalUser } from '../database/rugby-stats.database';

@Injectable({
  providedIn: 'root'
})
export class LocalAuthService {
  /**
   * Hash password using native Web Crypto API (SHA-256)
   * No external library required
   */
  async hashPassword(password: string): Promise<string> {
    const encoder = new TextEncoder();
    const data = encoder.encode(password);
    const hashBuffer = await crypto.subtle.digest('SHA-256', data);
    
    // Convert to hex string
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray
      .map(b => b.toString(16).padStart(2, '0'))
      .join('');
    
    return hashHex;
  }

  /**
   * Verify password against stored hash
   */
  async verifyPassword(password: string, storedHash: string): Promise<boolean> {
    const hash = await this.hashPassword(password);
    return hash === storedHash;
  }

  /**
   * Create local user (for setup/testing)
   * Must be done before login
   */
  async createLocalUser(
    email: string,
    password: string,
    prenom: string,
    nom: string
  ): Promise<LocalUser> {
    const existing = await db.local_users.get(email);
    if (existing) {
      throw new Error('Utilisateur déjà existe');
    }

    const passwordHash = await this.hashPassword(password);
    const now = new Date().toISOString();

    const user: LocalUser = {
      id: email,
      email,
      prenom,
      nom,
      passwordHash,
      createdAt: now,
      lastLoginAt: now
    };

    await db.local_users.add(user);
    return user;
  }

  /**
   * Verify local user credentials
   */
  async verifyLocalUser(
    email: string,
    password: string
  ): Promise<LocalUser | null> {
    const user = await db.local_users.get(email);
    if (!user) return null;

    const isValid = await this.verifyPassword(password, user.passwordHash);
    if (!isValid) return null;

    // Update lastLogin
    user.lastLoginAt = new Date().toISOString();
    await db.local_users.put(user);

    return user;
  }

  /**
   * Get all local users (for testing)
   */
  async getAllLocalUsers(): Promise<LocalUser[]> {
    return db.local_users.toArray();
  }

  /**
   * Delete local user
   */
  async deleteLocalUser(email: string): Promise<void> {
    await db.local_users.delete(email);
  }
}
```

## Limitation Importante

**Mode local = Offline only**

Pas de synchronisation Firestore possible en mode local. Pour synchroniser:
1. Passer en mode Firebase
2. Effectuer réauthentification (voir Phase 09)
