# Phase 03 - PWA Configuration

## Objectif

Configurer l'application comme Progressive Web App (installable, offline-capable).

## Étapes

### 1. Générer PWA Configuration

```bash
ng add @angular/pwa
```

Cela crée automatiquement:
- `ngsw-config.json` - Service Worker config
- `manifest.webmanifest` - PWA manifest
- Icons dans `src/assets/`

### 2. Configurer manifest.webmanifest

Éditer `src/manifest.webmanifest`:

```json
{
  "name": "Rugby Stats Collector",
  "short_name": "Rugby Stats",
  "theme_color": "#0056b3",
  "background_color": "#ffffff",
  "display": "standalone",
  "scope": "/",
  "start_url": "/",
  "icons": [
    {
      "src": "assets/icons/icon-192x192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "assets/icons/icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ],
  "screenshots": [
    {
      "src": "assets/screenshots/screenshot1.png",
      "sizes": "540x720",
      "type": "image/png"
    }
  ]
}
```

### 3. Configurer Service Worker

Éditer `ngsw-config.json`:

```json
{
  "$schema": "./node_modules/@angular/service-worker/config/schema.json",
  "index": "/index.html",
  "assetGroups": [
    {
      "name": "app",
      "installMode": "prefetch",
      "updateMode": "prefetch",
      "resources": {
        "files": [
          "/favicon.ico",
          "/index.html",
          "/*.css",
          "/*.js"
        ]
      }
    },
    {
      "name": "assets",
      "installMode": "lazy",
      "updateMode": "lazy",
      "resources": {
        "files": [
          "/assets/**",
          "/*.(svg|cur|jpg|jpeg|png|apng|webp|gif|otf|ttf|woff|woff2)"
        ]
      }
    }
  ],
  "dataGroups": [
    {
      "name": "firestore-cache",
      "urls": ["/firestore/**"],
      "cacheConfig": {
        "strategy": "performance",
        "maxAge": "6h",
        "maxSize": 100
      }
    }
  ]
}
```

### 4. Enregistrer Service Worker

Éditer `src/main.ts`:

```typescript
import { bootstrapApplication } from '@angular/platform-browser';
import { appConfig } from './app/app.config';
import { AppComponent } from './app/app.component';

if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/ngsw-worker.js')
    .then(registration => console.log('Service Worker registered'))
    .catch(err => console.error('Service Worker registration failed:', err));
}

bootstrapApplication(AppComponent, appConfig)
  .catch(err => console.error(err));
```

### 5. Mettre à jour index.html

Éditer `src/index.html`:

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Rugby Stats Collector</title>
  <base href="/">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="theme-color" content="#0056b3">
  <link rel="icon" type="image/x-icon" href="favicon.ico">
  <link rel="manifest" href="manifest.webmanifest">
</head>
<body>
  <app-root></app-root>
  <noscript>
    <p>Cette application nécessite JavaScript pour fonctionner.</p>
  </noscript>
</body>
</html>
```

### 6. Tester la PWA localement

```bash
# Build production
ng build --configuration production

# Servir le build
npx http-server dist/games-stats -p 8080 -c-1

# Visiter http://localhost:8080
# Ouvrir DevTools → Application → Manifest
```

### 7. Activer mode offline

Dans DevTools → Network → Select "Offline" → L'app fonctionne toujours!

### 8. Tester sur appareil physique

```bash
ng build --configuration production
firebase hosting:channel:deploy preview-channel
# Partager l'URL et tester sur mobile
```
