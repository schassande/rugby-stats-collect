# Phase 00 - Vue d'Ensemble du Projet

## Objectif

Collecter des événements de match de rugby en temps réel avec une application PWA offline-first, synchronisée vers Firestore.

## Stack Technologique

| Composant | Technology | Version |
|-----------|-----------|---------|
| **Framework** | Angular | 18+ |
| **UI Components** | PrimeNG | 18 |
| **Local DB** | Dexie.js | 4+ |
| **Backend DB** | Firestore | Cloud |
| **Auth** | Firebase Auth | 10+ |
| **PWA** | Service Worker | Native |
| **Forms** | Reactive Forms | Angular 18 |
| **State** | RxJS | 7+ |
| **Build** | Angular CLI | 18 |

## Délivrables

1. **Application Web Progressive (PWA)** installable
2. **Mode offline-first** avec IndexedDB + Queue locale
3. **Authentification** Email/Password + Google
4. **Synchronisation** automatique vers Firestore
5. **Collecte d'événements** rugby optimisée (saisie rapide)
